Architecture & Tech Stack

The system is fundamentally built to be self-reliant and extremely fast. We avoided the traditional JS-heavy SPA approach and opted for a pure Hypermedia architecture.

  • Backend: Django 6.0 — Used for the core ORM, authentication, and secure admin interface.
  • Frontend Interactivity: HTMX & Alpine.js — Handling dynamic partial reloads and state without writing custom JS endpoints.
  • Database: PostgreSQL — Housing massive 100-year historical market datasets and EBM models.
  • Styling: Tailwind CSS — For rapid, scalable, and highly customized UI rendering.

The "Why"

Relying on public financial tools means you are digesting the exact same information, at the exact same time, as everyone else. True edge in the market requires proprietary infrastructure. This platform allows us to correlate macroeconomic shifts with unconventional cycle data at a scale previously reserved for institutional quant desks.
